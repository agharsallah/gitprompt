Rules

The same checks just arch and cargo test run. Any finding fails CI.

    Test coverage

    Lines of shipped code that the Rust tests run (cargo llvm-cov; test files, examples and main.rs are left out). Not part of the modularity score: it measures how well tested the code is, not how it is cut.

    Crate layers

    Each crate uses only crates below it. Lines show the shortest picture: an edge already implied through another crate is hidden until you hover a crate (all its direct dependencies light up). Select a crate to open its modules.

    Crates

    Propagation cost: the share of module pairs where a change can reach the other through dependencies (lower is more modular). I instability, A abstractness, D distance from the main sequence (Martin): shown for context, not scored.

    Abstractness and instability

    Robert C. Martin's chart. Stable crates (left) that others build on are safest when abstract (top); a concrete stable crate such as a shared kernel sits bottom left by design. Context only.
